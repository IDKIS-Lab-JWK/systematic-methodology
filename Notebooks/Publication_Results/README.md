# Publication results - version 4

Open `Publication_Results_4.ipynb` for the executed analysis, or
`output_4/Publication_Results_4.html` for its browser edition. This is the only
publication notebook included. All 13 pipelines and scientific tables,
statistics, CT images, Grad-CAM galleries and radiologist summaries are retained.
Public case labels are R01-R20.

The public copy removes saved audit displays and local paths and replaces
original case identifiers with review labels. Original audits, identifier
linkage, verbatim correspondence, full patient prediction files, split
membership and cached arrays are not distributed. The original notebook stays
unchanged in the source workspace. Companion modules are scientific analysis
source, not preparation intermediates.

Saved outputs can be read without data or a model environment. Recomputing
patient bootstrap intervals, paired tests or attribution maps requires the
authorized private source results, splits, review inputs and images. Aggregate
tables cannot recreate those tests. Running all cells without private inputs
is not supported. Build, execute and verification utilities also require those
inputs; confidential original release manifests are not distributed.

The complete public case report is
`../../Case_Study/FlexiCT_20_Case_Study.pdf`. It compiles existing S10/S11
figures and S12-S14 interpretations without rerunning inference. No case was
relabeled or removed from performance calculations. R20 retains provisional
linkage. The selected-case comparison does not estimate unbiased performance.
